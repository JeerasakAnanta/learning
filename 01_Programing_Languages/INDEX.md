# 01_Programing_Languages - Programming Languages & Fundamentals

Core programming languages and fundamental coding concepts.

## 📂 Projects in this category

| Project | Language | Description |
|---------|----------|-------------|
| c++ | C++ | Systems programming, competitive coding |
| go | Go | Concurrent programming, backend services |
| java | Java | Object-oriented programming, enterprise patterns |
| javascript | JavaScript | Client-side scripting, DOM manipulation |
| python | Python | Data processing, scripting, utilities |
| rust | Rust | Memory safety, systems programming |
| typeScript | TypeScript | Typed JavaScript, advanced type systems |
| zig | Zig | Low-level programming, language design |
| html | HTML | Web markup and structure |
| pygame | Pygame | Python game development |

## 🎯 Learning Recommendations

**Beginners:**
- Start with Python or JavaScript for fundamentals
- Move to TypeScript for typed JavaScript

**Intermediate:**
- Learn Go for concurrent programming
- Explore Rust for memory safety concepts

**Advanced:**
- Systems programming: C++, Rust, Zig
- Game development: Pygame
